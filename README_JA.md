# KipfelNav(テスト版)

Galaxy のナビゲーションバー(3ボタン)の上に、動くキプフェルを重ねて表示するための自分用アプリ。
今はその前段階のテスト版で、確認用の図形を描くだけ。

## 仕組み

- アクセシビリティサービスの重ね描き層(`TYPE_ACCESSIBILITY_OVERLAY`)を画面全体に1枚張る。
  この層は AOSP の重なり順ではナビバーやキーボードより上に来る。
- タップはすべて素通りさせる(`FLAG_NOT_TOUCHABLE`)。押しているのは純正のボタン。
- 画面の内容は読まない(`canRetrieveWindowContent="false"`)。

## テスト版で確かめること

| 確認すること | 見るところ |
|---|---|
| ナビバーの上に描けるか | 水色の帯とオレンジの四角(1〜3)がナビバーに重なって見える |
| アニメーションが滑らかか | 白い点が帯の上を左右に動き続ける |
| キーボードの上に描けるか | 入力欄でキーボードを出したとき、マゼンタの「KB」がキーボードの上に見える |
| Fold の開閉・回転に追従するか | 開閉や回転のあと、帯の位置と画面上部の数値が変わる |
| タップが素通りするか | 四角の上からでも、戻る/ホーム/履歴が普通に押せる |

## 入れ方

1. APK をスマホに入れる(「提供元不明のアプリ」の許可が必要)
2. アプリを開いて「アプリ情報を開く」→ 右上の︙ →「制限付き設定を許可」
3. 「アクセシビリティ設定を開く」→ インストール済みアプリ →「KipfelNav 重ね描き(テスト)」をオン

止めるときは、アクセシビリティ設定でオフにする。

## ビルド

Android SDK(platform 36、build-tools 36)と JDK 17 以上が必要。

```
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```
