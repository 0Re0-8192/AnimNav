# AnimNav

[English](README.md)

Android の 3 ボタンナビゲーションバーのボタンの上に、**動く画像**(GIF・WebP・PNG 連番)を重ねて表示するアプリです。
Galaxy Z Fold7 + Good Lock の NavStar で作りました。ナビバーが出る端末なら動くはずですが、位置の合わせ直しは必要です。

> 個人の趣味で作ったアプリです。Samsung・Google とは関係ありません。**絵は同梱していません**。自分で用意した画像を使います。

## 仕組み

NavStar のようなナビバー着せ替えアプリは、ボタンのアイコンを好きな画像に替えられますが、動かすことはできません。
AnimNav は本物のボタンはそのまま残して(押せます)、その上にアニメーションを重ねて描きます。

- ナビバーに沿って、タッチを素通りさせる `TYPE_ACCESSIBILITY_OVERLAY` の窓を 1 枚置きます。この種類の窓は、ナビバーやキーボードより上に来ます。タッチはすべて、下の本物のボタンに届きます。
- 本物のボタンのアイコンは、透明な画像にしておきます。そうすると、重ねた絵だけが見えます。
- ナビバーに合わせて動きます。アプリが全画面になるときは、バーと一緒に沈みながら消えます。ロック画面では「戻る」だけを描きます。キーボード表示中は、「戻る」を「キーボードを閉じる」の絵に替えます。ナビバーが縦になる向き(横向きの端末)では、端に合わせて描きます。
- 全画面のアプリでスワイプしてナビバーを出すと、Android がそれを少し遅れて(約 0.3 秒)アプリに知らせます。そこで、バーが先に出たあとに、横から滑り込むように出して、遅れが自然に見えるようにしています。入り方は選べます。

## 入れ方

1. APK を入れます(提供元不明のアプリの許可が必要です)。
2. アプリを開いて「アプリ情報を開く」→ ︙ →「制限付き設定を許可」
3. 「アクセシビリティ設定を開く」→ インストール済みアプリ →「AnimNav」をオン
4. ナビバーの着せ替えアプリで、ボタンのアイコンを透明な画像にします。
5. AnimNav で、ボタンごとに画像を選びます。

## 画像

| 形式 | 動き |
|---|---|
| GIF・WebP | アニメも可。速さはファイルのとおり |
| PNG 1 枚 | 止め絵 |
| PNG 連番の ZIP | ファイル名の順(数字は数として比べる)に再生。1 コマの長さはアプリで設定(初期値 150ms) |

画像はアプリの専用領域にコピーされます。「ドットをくっきり」をオンにすると、整数倍で拡大するので、ドット絵がくっきり見えます。

## 位置

位置は画面の大きさに対する割合で持ちます。小さい画面、大きい画面(幅 600dp 以上)、ナビバーが横のとき、で別々に保存します。
初期値は Galaxy Z Fold7 + NavStar の実測値です。

| 画面 | 真ん中のボタン | 間隔 |
|---|---|---|
| 小さい画面(閉じた状態) | 50.0% | 27.9% |
| 大きい画面(開いた状態) | 71.8% | 13.2% |
| 小さい画面でバーが横 | 50.0%(高さに対して) | 28.2% |

ほかの端末では、「位置合わせ用の枠を表示」をオンにして、スライダーで合わせてください。

## プライバシーと権限

ナビバーより上に描けるのがアクセシビリティサービスだけなので、アクセシビリティサービスとして作っています。
画面に出ているウィンドウの一覧を見るために `canRetrieveWindowContent` を宣言していますが、使うのは各ウィンドウの**種類・位置・タイトルだけ**で、ナビバーが出ているかを知るためです。
文字などの中身は読みません。**インターネットの権限はなく**、何も収集しません。画像は端末の中にだけ置かれます。

## 制限

- 全画面のアプリでスワイプしてナビバーを出すと、バーより約 0.3 秒遅れて出ます。Android 側がウィンドウの変化を遅れて知らせるためで、アプリ側では早められません。
- Galaxy Z Fold7(One UI、Android 16)でしか試していません。縦のナビバーを見分けるためのウィンドウのタイトルは、英語と日本語(と、未確認の韓国語)にだけ合わせています。
- **スワイプの先読み**(実験機能、初期値はオフ)は、アプリが全画面のあいだ、画面の端に見えない細いタッチ用の帯を置いて、スワイプを早く見つけます。帯の中から始まるタッチはアプリに届かないので、音ゲーなどでは使わないでください。

## ビルド

Android SDK(platform 36、build-tools 36)と JDK 17 以上が必要です。

```
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```

APK は `app/build/outputs/apk/debug/` に出ます。
