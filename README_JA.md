# KipfelNav

Galaxy のナビゲーションバー(3ボタン)の上に、動く画像を重ねて表示する自分用アプリ。
Galaxy Z Fold7 + Good Lock の NavStar で使う前提。

## 仕組み

- アクセシビリティサービスの重ね描き層(`TYPE_ACCESSIBILITY_OVERLAY`)を、画面の下端に1枚張る。
  この層はナビバーやキーボードより上に来る(Fold7 / One UI で確認済み)。
- タップはすべて素通り(`FLAG_NOT_TOUCHABLE`)。押しているのは純正のボタン。
- ナビバーが出ているかは、アプリ向けの画面情報(WindowMetrics)と、アクセシビリティの
  ウィンドウ一覧の両方で見る。スワイプで一時的に出したナビバーは、前者では「隠れている」扱いに
  なる(Android の仕様)ので、後者で拾う。ウィンドウ一覧を見るために
  `canRetrieveWindowContent` を有効にしているが、使うのはウィンドウの種類・位置・タイトルだけで、
  中身(文字など)は読まない。
- 50ms ごとと、ウィンドウが出入りしたときに、画面の状態(ナビバー・キーボード・ロック)を見る。
  画面が消えているあいだは止める。
- 「位置合わせ用の枠」をオンにすると、判定の中身(ウィンドウ一覧など)も画面に出る。
- カバー画面を横にしたときは、ナビバーが画面の右端(または左端)に縦に並ぶので、それに合わせて描く。
  右端のときは上から「履歴・ホーム・戻る」(縦向きの並びを 90° 回したもの)。
- ナビバーがないとき(ロック画面・全画面表示)は描かない。
  消えるとき・出てくるときは、外へ沈みながらフェードする。
- スワイプで一時的に出したナビバーは、ウィンドウ一覧が Android 側の都合で 0.2 秒ほど遅れて届く
  (消えるときは、バーの位置を追いかけて一緒に沈む)。
  遅れて出るときは、バーが先に出ているので、バーの横からスライドして入ってくる
  (下のバーなら画面の右端から、横のバーなら画面の下端から。右・下のボタンから順に、0.32 秒)。
  そこで全画面のあいだだけ、画面の端(ナビバー側と、ステータスバーも隠れていれば上端)に
  見えない細い帯を置き、そこから始まったスワイプを自分で見つけて、バーと同じ動きで先に出し始める(先読み)。
  - 実験機能で、初期値はオフ(音ゲーなど、画面の端からのタッチを使うアプリでは使わない)。
  - Android のスワイプ判定は画面全体のタッチを横から見ているので、帯があってもナビバーはふつうに出る。
  - そのかわり、全画面のときは帯の中のタッチがアプリに届かない。帯の幅はアプリで変えられる(初期値 12dp)。
  - バーが 1 秒以内に出てこなければ、空振りとして引っ込める。
  - 帯より内側から始めたスワイプは、これまでどおり少し遅れて出る。
  - 「位置合わせ用の枠」をオンにすると、帯が赤く見え、先読みの当たり・空振り・間に合わなかった回数も出る。
- ロック中(パスワード入力画面など)は、戻るだけを描く。
- キーボード表示中は、戻るの位置を「キーボードを閉じる」の絵に切り替える。

## 画像

絵はアプリにもこのリポジトリにも入れない(素材の規約で再配布できないため)。
アプリの「画像」で、ボタンごとに取り込む。

| 形式 | 動き |
|---|---|
| GIF・WebP | アニメも可。速さはファイルのとおり |
| PNG 1枚 | 止め絵 |
| PNG 連番の ZIP | ファイル名の順(数字は数として比べる)に再生。1コマの長さはアプリで設定(初期値 150ms) |

「キーボードを閉じる」を設定しなければ、キーボード表示中も戻るの絵のまま。
旧版(v0.2)の「4行まとめ画像」が残っていれば、画像のないボタンはそこから切り出して使う。

「ドットをくっきり」がオンのときは、元の絵の整数倍か整数分の1の大きさに寄せる。

NavStar 側のボタン画像は透明な PNG にしておく(下のボタンが透けて見えないように)。

## 位置

位置は画面の幅に対する割合で持つ。閉じた画面と開いた画面で別々に保存する。
初期値は Fold7 + NavStar の実測値。

| 画面 | 真ん中のボタン | 間隔 |
|---|---|---|
| 閉じた画面 | 50.0% | 27.9% |
| 開いた画面(縦横とも) | 71.8% | 13.2% |
| 閉じた画面の横向き(ナビバーが横) | 50.0%(高さに対して) | 28.2% |

ずれていたら、アプリの「位置合わせ」のスライダーで直す。

## 入れ方

1. APK をスマホに入れる(「提供元不明のアプリ」の許可が必要)
2. アプリを開いて「アプリ情報を開く」→ 右上の︙ →「制限付き設定を許可」
3. 「アクセシビリティ設定を開く」→ インストール済みアプリ →「KipfelNav」をオン
4. 「画像」でボタンごとに画像を選ぶ

止めるときは、アクセシビリティ設定でオフにする。

## ビルド

Android SDK(platform 36、build-tools 36)と JDK 17 以上が必要。

```
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```
