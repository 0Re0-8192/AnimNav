# AnimNav

[English](README.md) · [更新履歴](CHANGELOG.md)

Android の 3 ボタンナビゲーションバーのボタンの上に、**動く画像**(GIF・WebP・PNG 連番)を重ねて表示するアプリです。

> 個人の趣味で作ったアプリです。Samsung・Google とは関係ありません。**絵は同梱していません**。自分で用意した画像を使います。

## 機能

- **戻る**・**ホーム**・**履歴**・**キーボードを閉じる**に、それぞれ別の画像を設定できます。GIF、WebP、PNG 1 枚、PNG 連番の ZIP に対応。
- タップは本物のボタンに届きます。AnimNav は上に描くだけです。
- ナビバーに合わせて動きます。全画面のアプリでは、バーと一緒に沈みながら消えます。ロック画面では「戻る」だけを描きます。キーボード表示中は「戻る」を「キーボードを閉じる」に替えます。バーが縦のときは、端に合わせて描きます。
- 全画面のアプリでスワイプしてバーを出すと、バーのあとから画像が滑り込んで出ます。入り方は選べます。
- Material 3 の設定画面(画像のプレビュー付き)、ダークモード、日本語・英語に対応しています。

**Galaxy Z Fold7**(One UI、Android 16)と、Good Lock の NavStar で作って試しました。3 ボタンのバーが出るほかの端末でも動くはずですが、位置の合わせ直しは必要です。

## ダウンロード

最新の APK は [Releases](../../releases) にあります。Android 11 以上が必要です。APK はリリース用の鍵で署名してあり、証明書の SHA-256 は次のとおりです。

```

```

## 入れ方

1. APK を入れます(提供元不明のアプリの許可が必要です)。
2. アプリを開いて「アプリ情報を開く」→ ︙ →「制限付き設定を許可」
3. 「アクセシビリティ設定を開く」→ インストール済みアプリ →「AnimNav」をオン
4. ナビバーの着せ替えアプリ(NavStar など)で、ボタンのアイコンを透明な画像にします(本物のアイコンが透けないように)。
5. AnimNav で、ボタンごとに画像を選びます。

## 画像

| 形式 | 動き |
|---|---|
| GIF・WebP | アニメも可。速さはファイルのとおり |
| PNG 1 枚 | 止め絵 |
| PNG 連番の ZIP | ファイル名の順(数字は数として比べる)に再生。1 コマの長さはアプリで設定(初期値 150ms) |

画像はアプリの専用領域にコピーされます。「ドットをくっきり」をオンにすると、整数倍で拡大するので、ドット絵がくっきり見えます。

## 位置

位置は画面の大きさに対する割合で持ちます。小さい画面、大きい画面(幅 600dp 以上)、ナビバーが横のとき、で別々に保存します。
初期値は Galaxy Z Fold7 + NavStar の実測値です。

| 画面 | 真ん中のボタン | 間隔 |
|---|---|---|
| 小さい画面(閉じた状態) | 50.0% | 27.9% |
| 大きい画面(開いた状態) | 71.8% | 13.2% |
| 小さい画面でバーが横 | 50.0%(高さに対して) | 28.2% |

ほかの端末では、「位置合わせ用の枠を表示」をオンにして、スライダーで合わせてください。

## 仕組み

ナビバーの着せ替えアプリは、ボタンのアイコンを好きな画像に替えられますが、動かすことはできません。AnimNav は本物のボタンはそのまま残して、その上に描きます。

- ナビバーに沿って、タッチを素通りさせる `TYPE_ACCESSIBILITY_OVERLAY` の窓を 1 枚置きます。この種類の窓は、ナビバーやキーボードより上に来ます。
- 本物のアイコンは透明な画像にしておくので、動く絵だけが見えます。
- ナビバーが出ているかは、ウィンドウのインセットで調べます。全画面のアプリでスワイプして出したバーは、Android がアプリには「隠れている」と伝えるので、画面に出ているウィンドウの一覧からも調べます。この一覧は Android 側で約 0.3 秒遅れて更新されるので、バーのあとから画像が滑り込んで出ます。

## プライバシーと権限

ナビバーより上に描けるのがアクセシビリティサービスだけなので、アクセシビリティサービスとして作っています。
画面に出ているウィンドウの一覧を見るために `canRetrieveWindowContent` を宣言していますが、使うのは各ウィンドウの**種類・位置・タイトルだけ**で、ナビバーが出ているかを知るためです。
文字などの中身は読みません。**インターネットの権限はなく**、何も収集しません。画像は端末の中にだけ置かれます。

## 制限

- 全画面のアプリでスワイプして出したバーには、約 0.3 秒遅れて画像が出ます。Android 側がウィンドウの変化を遅れて知らせるためで、アプリ側では早められません。
- Galaxy Z Fold7 でしか試していません。縦のナビバーを見分けるためのウィンドウのタイトルは、英語と日本語(と、未確認の韓国語)にだけ合わせています。
- **スワイプの先読み**(実験機能、初期値はオフ)は、アプリが全画面のあいだ、画面の端に見えない細いタッチ用の帯を置いて、スワイプを早く見つけます。帯の中から始まるタッチはアプリに届かないので、音ゲーなどでは使わないでください。

## ビルド

Android SDK(platform 36、build-tools 36)と JDK 17 以上が必要です。

```
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```

APK は `app/build/outputs/apk/debug/` に出ます。

リリース用に署名するときは、`build.gradle` と同じ場所に `keystore.properties` を作ります(Git の管理外です)。

```
storeFile=/path/to/your.jks
storePassword=...
keyAlias=...
keyPassword=...
```

そのあと `./gradlew assembleRelease` を実行します。

## 不具合の報告

不具合の報告は歓迎です。端末名、Android のバージョン、「位置合わせ用の枠を表示」をオンにした状態のスクリーンショットか画面録画を添えてください。
